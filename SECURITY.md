# Aviso de seguridad

La versión estática guarda datos en el almacenamiento del navegador y no tiene autenticación. Cualquier persona que use ese perfil de navegador podría ver los datos guardados. No está preparada para datos personales reales ni para despliegue productivo.

No subas archivos de empleados al repositorio. Para uso real, migrá a un backend con autenticación, autorización por roles, base de datos persistente, HTTPS, copias de seguridad y controles de acceso.
